# 구현 상태 및 검증 경계

## 구현한 동작

- 온디맨드 N2 워커 최대 2대: 큐 기반 기동, 호스트당 2슬롯, 15분 유휴 종료, 종료 전 작업 배정 차단, Compute 요청 재시도. Supabase 전용 스키마 및 Vertex Express 연결. 클라우드 실제 배포와 검증 상태는 [배포 문서](gemini-deployment.md)를 확인한다.

- 서버·웹·VM 워커 별도 패키지 및 빌드, GitHub CI.
- Google ID 토큰 검증, HttpOnly 세션, 사용자 소유 데이터 검증, CSRF, 요청 빈도 제한.
- 라이트/다크 웹, 로그인, 학습 목록, 설명, 퀴즈, 문제 목록, Monaco 편집기, 기록, 전체 화면 네트워크 복구.
- 학습 주제 47개(P0 30/P1 10/P2 7)와 퀴즈. P0 30개 주제의 입력값 변경·단계 이동 설명용 예제. 실행 문제 15개, 문제마다 공개 테스트와 3개 언어 권장 코드.
- 개념 퀴즈는 주제별 3문항으로 총 141개이며 개별 해설과 문항 이동을 지원한다. 기존 47문항에 작성된 응용·경계 사례 94문항을 추가했다. 정답·해설은 제출 전 응답에서 제외하고 문항 ID와 내용 스냅샷으로 채점한다.
- P0 30개 주제는 각각 3개의 선택 가능한 입력 시나리오(총 90개)를 제공한다. 같은 알고리즘의 기본·경계·반례 입력을 비교하며 자유 입력도 유지한다. 그래프는 분기·사이클·단절 사례를 제공한다. P1/P2의 추가 실행 모델은 이번 확장 범위에 포함하지 않는다.
- 배열·그래프·트리·객체 참조를 드래그 또는 방향키로 이동하고 자동/원형/격자 배치, 확대·축소·화면 맞춤·초기화를 사용할 수 있다. 위치는 동일 예제의 단계 이동 중 유지되며 예제 변경 시 초기화한다. 화면 배치는 데이터와 알고리즘 결과를 변경하지 않는다. 그래프는 20개, 배열 30개, 트리 31개, 객체 30개 표시 상한을 둔다.
- 자동 저장 충돌 검사, 불변 코드 스냅샷, 재실행 시 같은 기록 갱신, 100건 초과 가장 오래된 기록 삭제, 생성 후 30일 만료.
- 테스트 전체 실행 및 사전 입력 실행, 영속 실행 큐, 요청 중복 방지, 최대 10개 임대, 워커 heartbeat/지연 결과 차단.
- Firecracker jailer에서 Python 3.10/C++20/Java21 실행하는 워커와 게스트 소스. 사용자 프로그램 메모리 512MiB, 테스트 10초, VM 768MiB, 컴파일 30초, 제출 전체 120초는 실험 시작값이다.
- Python trace, C++ GDB, Java JDI의 라인/변수/호출 스택 추적. 사용자 정의 객체의 필드·객체 ID·순환/공유 참조 표시. 모양이 명확한 배열/인접 리스트는 이름과 무관하게 선택하고 애매하면 변수 보기를 제공한다. 채점과 추적은 별도 실행이다.
- 무료 분석: 정확한 권장 코드 또는 검증된 토큰·줄/들여쓰기 구조 일치에 한해 등록된 Big-O를 표시한다. 다른 코드는 반복문·정렬·리스트 앞 삭제 등 정적 점검과 실행 시간/메모리를 제공한다. 임의 코드의 정확한 Big-O를 증명했다고 표시하지 않으며 LLM을 호출하지 않는다.
- LLM 리뷰 3개 결과, 월 무료 3건, KST 월초 갱신, 예약 후 성공 시 소비, 실패 시 반환, 삭제해도 소비 복원 없음.
- 기록별 PDF 생성과 Google Drive 업로드 흐름. 실행 처음/중간/마지막 장면의 배열·그래프·트리 그림과 변수 스냅샷을 함께 포함한다.
- Android Kotlin WebView 앱과 빌드 CI. Credential Manager Google 로그인, 5분 일회용 nonce, 허용 origin/최상위 프레임 브리지, 서버 측 학습 전용 세션, 네이티브 네트워크 오류 CTA. 웹/태블릿 폭과 무관하게 코드 작성은 제공하지 않는다.
- Python/C++은 seccomp로 자식 프로세스·스레드 생성을 차단한다. Java 21은 별도 진입점의 학습 정책으로 사용자 Thread/ThreadGroup과 프로세스 생성을 제한하고 JVM 내부 스레드는 유지한다. VM 격리가 보안 경계이며 언어 정책 자체를 보안 샌드박스로 간주하지 않는다.
- 테스트 및 추적 실행 전 작업 디렉터리를 복원해 이전 실행의 파일 변경·심볼릭 링크 영향을 제거한다. 운영 워커 시작 시 커널/rootfs SHA-256과 HTTPS API를 요구한다.
- 버전별 DB 마이그레이션, GCS gzip 추적 저장·체크섬·삭제 outbox, 관리자 콘텐츠 검증/게시 CLI·감사 이벤트, 운영 상태 API와 유지보수 작업.
- Cloud Run 통합 이미지와 GCP Terraform(Cloud Run/GCS/Secret 참조/OIDC 스케줄러). 운영 워커 2대와 전용 네트워크·IAM 생성 완료. Supabase 실제 TLS 연결과 마이그레이션 검증 완료. 웹/API 배포 및 종단 검증 상태는 배포 문서를 따른다.

## 현재 지원 경계

1. 추적은 깊이/개수/크기 상한이 있으며 모든 언어 런타임 객체를 완전 재구성하지 않는다. Python slots/컨테이너 별칭, C++ 최적화·특수 포인터, Java 일부 컬렉션/VM 내부 객체 등은 제한적이다. 일반 객체 참조와 의미상 그래프/트리는 구분한다.
2. 자유 코드의 정확한 점근적 복잡도 추론은 일반적으로 보장할 수 없다. 미지원 결과·정적 점검·실측을 명확히 구분한다.
3. P1/P2는 설명과 퀴즈를 제공하며 고급 주제 전체에 인터랙티브 모델이나 별도 실행 문제가 있는 것은 아니다. P0 실행 연습 문제는 15종이며 문제 은행을 계속 확장할 수 있다.
4. PDF는 입력 데이터 16MiB와 인스턴스당 동시 2건을 시작 한도로 둔다. 한도 초과 시 내용을 몰래 생략하지 않고 명시적으로 실패한다. 초대형 PDF 비동기 분할/병합은 지원하지 않는다.
5. Java의 일반 사용자 스레드 제한을 제공하지만 리플렉션/Unsafe 등 적대적 우회까지 완전 증명한 것은 아니다. 운영 보안 감사와 부하 시험은 별도로 필요하다.

## 사용자 결정 및 외부 연결 대기

- **결제 미정(사용자 확인)**: PG·상품 수량·가격·환불 정책이 미정이므로 실제 결제/추가 이용권은 비활성이다. 가짜 주문/성공 처리도 제공하지 않는다. 정책이 결정되면 공급자 연동과 결제 검증을 구현해야 한다.
- **배포 구성 확정(사용자 확인)**: GCP `algostep` 하나, Cloud Run, Supabase Free, 유휴 시 중지하는 N2 워커 최대 2대. [온디맨드 배포](ondemand-deployment.md) 참조. 실제 계정 연결 검증은 진행 중이다.
- Android APK는 설정 없는 빌드 검증용으로 생성한다. 실제 도메인, OAuth Android 패키지/서명 인증서 등록, release 서명·실기기 로그인·Play 게시가 남아 있다.
- 백업/복원, 로그 보관·경보 임계치, 삭제 이력 재적용 정책은 [운영 절차](operations.md)에 있으며 실제 운영 계정에서 설정·훈련해야 한다.

## 외부 설정이 필요한 항목

- Google OAuth 클라이언트/허용 출처, Drive API 활성화 및 동의 화면.
- Gemini Developer API 키(기본 gemini-3.8-flash). 네이티브 구조화 응답·토큰 원장을 구현했으며 실제 키/과금 계정 연결이 필요하다. 명시적 설정으로 기존 OpenAI 호환 인터페이스도 지원한다.
- KVM 호스트, Firecracker/jailer, 검증된 커널·rootfs, 이미지 업데이트/서명 정책.
- 도메인·TLS·클라우드 계정. 이 저장소 생성으로 서비스가 인터넷에 배포되는 것은 아니다.

검증 증거와 최신 통과 여부는 GitHub Actions 및 `docs/verification.md`를 확인한다. 로컬 통합 테스트가 외부 인증·PG·프로덕션 VM 보안 검증을 대신하지 않는다.

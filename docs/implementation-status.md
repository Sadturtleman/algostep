# 구현 상태 및 검증 경계

## 구현한 동작

- 서버·웹·VM 워커 별도 패키지 및 빌드, GitHub CI.
- Google ID 토큰 검증, HttpOnly 세션, 사용자 소유 데이터 검증, CSRF, 요청 빈도 제한.
- 라이트/다크 웹, 로그인, 학습 목록, 설명, 퀴즈, 문제 목록, Monaco 편집기, 기록, 전체 화면 네트워크 복구.
- 초기 학습 주제 12개와 단일 선택형 퀴즈, 실행 문제 3개(이진 탐색/BFS/트리 순회), 문제마다 공개 테스트와 3개 언어의 권장 코드.
- 자동 저장 충돌 검사, 불변 코드 스냅샷, 재실행 시 같은 기록 갱신, 100건 초과 가장 오래된 기록 삭제, 생성 후 30일 만료.
- 테스트 전체 실행 및 사전 입력 실행, 영속 실행 큐, 요청 중복 방지, 최대 10개 임대, 워커 heartbeat/지연 결과 차단.
- Firecracker jailer에서 Python 3.10/C++20/Java21 실행하는 워커와 게스트 소스. 사용자 프로그램 메모리 512MiB, 테스트 10초, VM 768MiB, 컴파일 30초, 제출 전체 120초는 실험 시작값이다.
- Python trace, C++ GDB, Java JDI의 라인/변수/호출 스택 추적과 알려진 변수 패턴 기반 배열·그래프·트리 표시. 알 수 없는 구조는 변수 보기로 대체한다. 채점과 추적은 별도 실행하며 설명용 시각화와도 구분한다. 언어별 최종 검증 결과는 검증 기록을 참고한다.
- 무료 복잡도 분석: 검증된 권장 코드와 정확히 일치하는 경우에만 전체 프로그램의 시간/공간 복잡도를 반환한다. 그 외에는 미지원으로 표시하며 LLM을 사용하지 않는다.
- LLM 리뷰 3개 결과, 월 무료 3건, KST 월초 갱신, 예약 후 성공 시 소비, 실패 시 반환, 삭제해도 소비 복원 없음.
- 기록별 PDF 생성과 Google Drive 업로드 흐름. 실행 처음/중간/마지막 장면의 배열·그래프·트리 그림과 변수 스냅샷을 함께 포함한다.

## 출시 전에 남은 기능

1. 임의 객체 참조·변수 이름·사용자 정의 자료구조의 추적과 그래프/트리 자동 매핑 확장. 현재는 스칼라·배열·일부 표준 컬렉션 및 권장 코드의 변수 이름을 지원한다.
2. 권장 코드 일치 외의 무료 정적 분석과 지원 패턴 확장. 임의 코드의 정확한 Big-O를 보장하지 않는다.
3. 전체 P0 콘텐츠와 문제 확장, P1/P2 콘텐츠의 체계적 구성. 현재 12개 학습 주제는 전체 커리큘럼이 아니다.
4. PG 공급자·상품 수량·가격·환불 정책 확정 후 실제 결제/추가 이용권 구현.
5. Android 네이티브 WebView 패키지 및 Google 네이티브 로그인 연결. 현재는 모바일 반응형 학습 웹이며 APK는 없다.
6. 매우 큰 실행 결과를 위한 PDF 분량 정책과 추적 데이터 객체 스토리지 이전.
7. 런타임 내부 스레드와 사용자 스레드를 구분하는 단일 스레드 강제 정책. 현재 vCPU 1개와 cgroup PID 상한은 악용 자원 제한이며 단일 사용자 스레드 강제와 같지 않다.
8. 프로덕션 객체 스토리지, 운영 마이그레이션, 장기 운영 감사·백업·관측·관리자 콘텐츠 도구.

## 외부 설정이 필요한 항목

- Google OAuth 클라이언트/허용 출처, Drive API 활성화 및 동의 화면.
- LLM 엔드포인트·API 키·모델(현재 OpenAI 호환 chat-completions JSON 인터페이스).
- KVM 호스트, Firecracker/jailer, 검증된 커널·rootfs, 이미지 업데이트/서명 정책.
- 도메인·TLS·클라우드 계정. 이 저장소 생성으로 서비스가 인터넷에 배포되는 것은 아니다.

검증 증거와 최신 통과 여부는 GitHub Actions 및 `docs/verification.md`를 확인한다. 로컬 통합 테스트가 외부 인증·PG·프로덕션 VM 보안 검증을 대신하지 않는다.

원본의 시각적 구성에 이후 확정한 제품 요구사항을 적용했다. 전체 47개 개념의 종류별 분류와 검색, 개념→퀴즈→코드 문제 화면 분리, 사용 용도, 관리자·문의 기능을 유지한다. 모바일에는 코드 작성·실행 메뉴를 노출하지 않는다. OS 상태 표시줄은 웹에서 재현하지 않는다.

홈의 추천은 실제 이어보기 기록이 아니므로 ‘추천 학습’으로 표시한다. 예시 화면에 있는 정답·실행 결과·복잡도·리뷰 수치는 복사하지 않고 서버가 제공하는 실제 상태를 표시한다. 시각화는 테스트 결과·리뷰 탭을 전환해도 코드 옆에 계속 남아 있다. 그래프·트리·배열의 이동과 확대·축소 기능도 유지한다.

범위: 공통 스타일과 위 화면의 레이아웃 정렬. 모든 Figma 예외 상태 및 부가 화면을 픽셀 단위로 대조한 결과를 의미하지 않는다.

## 검증 및 배포 (2026-09-20)

- `npm run check`: 빌드·타입 검사 통과, 서버/워커 테스트 55개 통과. 별도 PostgreSQL 환경 검사 1개는 기존 조건에 따라 생략.
- 브라우저 테스트 17개 통과. 360/412/768/850/1024/1440px의 라이트·다크 가로 넘침, 모바일 하단 메뉴 이동, 리뷰 전환 시 시각화 유지 확인.
- Cloud Build `c8d1f888-3f10-4cf9-bc03-628fafaa619b` 성공, 기존 Cloud Run 이미지 업데이트 완료. 데이터베이스·IAM·워커 변경 없음.
- 운영 health/metrics 200, 익명 관리자·문의 API 401, 새 웹 번들 확인.
